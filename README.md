# THE SHATTERED AGES

**Tagline:** Build a realm. Raise a dynasty. Discover what lies beyond.

Standalone original persistent strategy RPG / 4X project.

## Current phase
Phase 0: architecture and vertical-slice planning.

## Core loop
GATHER → BUILD → RESEARCH → EXPLORE → FIGHT → DISCOVER → EXPAND → GOVERN

## Vertical slice target
- One starting region
- One settlement
- 10–15 buildings
- Five primary resources
- Storage/logistics
- One research tree
- Six unit types
- Four heroes
- 20–30 world-map locations
- Three ordinary ruins
- One major story ruin
- One NPC enemy faction
- PvE combat
- Limited protected PvP
- Basic alliance scaffolding
- Account/save architecture
- Founder Pack + cosmetic entitlement design
- Mobile-first UI with desktop adaptation

## Originality guardrails
This project must not copy protected names, characters, maps, UI, art, lore, terminology, magic systems, or distinctive expressive elements from existing fantasy/game franchises.

No Wheel/Pattern/One Power analogue. No recognizable Game of Thrones-style house clones. No copied city layouts or game UI.

## Architecture rule
Economy, combat, timers, inventory, purchases, and entitlements are server authoritative.

## No fake features
If a feature is unfinished, disable, omit, or clearly mark it. Never pretend multiplayer, purchases, alliances, save sync, or PvP work when they do not.

## Monetization
Planned later in test mode first: Founder Packs, cosmetics, optional season pass, optional Explorer's Guild membership. No direct sale of unbeatable military power.
