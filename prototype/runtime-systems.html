Live Runtime Systems

A visual reference for the five runtime systems added to the playable vertical-slice branch. Each system is backed by automated verification; this screen is intentionally a status surface rather than a fake production-game screenshot.

01 · SETTLEMENT

Turn Execution

VERIFIED

Food upkeep resolves before staffed production. Storage caps and starvation state are returned in one deterministic turn result.

02 · CONSTRUCTION

Cancel & Refund

VERIFIED

Active timed work can be cancelled before completion, with refund value reduced once work passes the halfway mark.

03 · WORLD

Expedition Runtime

VERIFIED

Travel advances by elapsed time, consumes supplies, arrives at destination, or becomes stranded when provisions fail.

04 · COMBAT

Resume Snapshot

VERIFIED

Unresolved encounters can be snapshotted with revision data, integrity checking, hero IDs, forces, and strict player binding.

05 · COMMERCE

Test Recovery

TEST ONLY

Verified test purchase/refund history can rebuild cosmetic entitlements. Live-mode and unverified events are rejected.
